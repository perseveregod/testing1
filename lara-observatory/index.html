    How it works

    Data

    Every number comes from completed five-minute bars. A return is the change from one bar's close to the next. If two bars are not exactly five minutes apart (the daily futures break, a weekend, a missing bar), no return is counted for that gap.

    Correlation map

    Each market's correlation with every other market is measured on the last 120 five-minute returns the two share (10 hours). A pair with fewer than 30 shared returns is shown as not measured and gets no line.

    Markets are placed so that distance follows correlation: the closer two markets sit, the more they moved together. It is a 3D approximation, and near-identical markets are nudged apart so both labels stay readable. Lines are drawn for correlations of 0.35 or stronger, blue for positive and orange for negative.

    The burst around each market is its last 120 returns laid out like a clock, oldest at the top and running clockwise. A longer spoke is a bigger move, on the same scale for every market. Blue is up, orange is down, and older spokes are fainter.

    Density surface

    Each ridge shows how 48 consecutive returns (4 hours) were spread out: left of zero is down, right is up, and height is how common that size of move was. Ridges step forward 25 minutes at a time, oldest at the back and the latest at the front.

    Each ridge is smoothed with the standard rule-of-thumb width for its sample size, so a peak needs several returns behind it to show up. Returns larger than the axis fall off the chart; the range in the card below gives the true extremes.

    Motion

    The slow sway is only there to show depth. It carries no data, and Pause stops it.
